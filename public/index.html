Delivery figures live in one spreadsheet. Grant spend lives in another. Someone matches them by hand every quarter.

Explore the proposed workflow +

A focused starting point

Agree the fields for one grant return. Bring approved activity and spend exports into a shared staging area, flag missing project codes and route the draft to its owner.

What we would measure

Preparation hours, missing entries and how many corrections are needed before sign-off.

Illustrative scenario / 02

For operations & leadership teams

Updates arrive by email, in different formats. The pack owner chases contributors and checks which version is final.

Explore the proposed workflow +

A focused starting point

Use one agreed update format, track submissions and send reminders. Make the review status visible before assembling a draft pack.

What we would measure

Time spent chasing, late submissions and the number of versions circulated for review.

Possible tools

Power Apps or a SharePoint list for updates, with Power Automate for reminders and approvals. Trustees still receive the format you agree.

07 / BEFORE WE START

The practical
questions.

Do we have to replace our current systems?+

The starting point is one report using information your systems can already provide. We assess available exports and connections first. If a reliable connection is not possible, we explain the constraint before agreeing a build.

Is this included in our Microsoft 365 subscription?+

Not necessarily. Requirements depend on the connectors, data storage, users and reporting tools involved. We check your existing licences and identify any additional subscription costs during scoping.

What should we bring to the first conversation?+

A redacted example of the last report, a list of its source systems and the person who puts it together. A walkthrough is enough to start; you do not need to send identifiable beneficiary records.

What if our data is messy?+

We identify gaps, conflicting definitions and duplicated records before automating them. Any necessary clean-up has to be scoped explicitly. Automation alone will not make unreliable source data accurate.
